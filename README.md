# Interpretable and Intervenable ML Models for Pediatric Appendicitis

An academic Machine Learning project focused on predicting pediatric
appendicitis using clinical and laboratory data.

## Overview

This project explores Machine Learning techniques for pediatric
appendicitis prediction using Python and Scikit-learn.

## Technologies Used

- Python
- Pandas and NumPy
- Scikit-learn
- Matplotlib and Seaborn
- Joblib

## Machine Learning Models

- K-Nearest Neighbors (KNN)
- Multi-Layer Perceptron (MLP)

## Project Workflow

1. Load and explore the dataset.
2. Handle missing values and preprocess categorical data.
3. Split the data into training and testing sets.
4. Train classification and regression models.
5. Evaluate model performance using appropriate metrics.
6. Save trained models for later use.

## Evaluation Metrics

Classification:
- Accuracy
- Precision
- Recall
- F1-score
- Confusion matrix

Regression:
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- R-squared (R²)

## Project Status

Academic project. Model performance and implementation details
will be documented after validating the source code and results.

## Disclaimer

This project is for educational purposes only and is not intended
for clinical diagnosis or medical decision-making.
